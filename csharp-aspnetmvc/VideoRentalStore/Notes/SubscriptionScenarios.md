# 🎬 Subscription Scenarios

## Free Tier
- Max **3 rentals total** (lifetime cap, not monthly).
- Acts as a demo mode.
- If a paid subscription expires, the user falls back to Free tier with whatever remaining free rentals they have left.
- Once all 3 are used, no more rentals unless upgrading.

## Basic Tier
- Monthly subscription (renewable).
- Max **5 rentals per month**.
- Resets count each billing cycle.
- If expired → user drops to Free tier (with remaining free credits, if any).

## Premium Tier
- Monthly subscription (renewable).
- **Unlimited rentals** during active subscription.
- If expired → user drops to Free tier (with remaining free credits, if any).

## VIP Tier (Optional)
- Could be treated as **lifetime unlimited** or **annual unlimited**.
- Distinguish it from Premium by duration or perks (e.g., no expiry, special discounts).
